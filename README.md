# Shocker OwnZ: Grow Empire — Alpha 0.4

Godot 4 Android-first game prototype.

## New in Alpha 0.4
- Branded title screen using the supplied Shocker OwnZ artwork
- Visual seedling / veg / flower / harvest-ready stages
- Plant training action
- Random Light Stress, Nutrient Imbalance and Pest events
- Diagnose/treat interaction
- Achievement system
- Room 02 expansion unlock
- Android export preset with package ID `com.shockerownz.growempire`

## Existing gameplay
Grow genetics, hunt phenotypes, manage water/light/RH/feed, harvest, dry/cure,
sell flower, save mothers, make clones, breed crosses, preserve Project 0 keepers,
complete dispensary contracts, buy upgrades, level up and complete missions.

## Make the APK
1. Install Godot 4.x.
2. Install Godot's Android export templates.
3. Configure Android SDK + JDK in Godot Editor Settings.
4. Import `project.godot`.
5. Run the project to test.
6. Project > Export > Android > Export Project.

The included Android preset exports to:
`build/ShockerOwnZ-GrowEmpire-Alpha04.apk`

A release build for Google Play will later need a private release keystore and store signing.
